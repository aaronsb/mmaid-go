# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

Be respectful. Disagree about the code, not the person. Assume good faith,
and give the benefit of the doubt to newcomers.

Unacceptable behaviour includes harassment, personal attacks, publishing
others' private information, and sustained disruption of discussion.

Report concerns to the maintainer by email at the address on the GitHub
profile of [@aaronsb](https://github.com/aaronsb). Reports are handled
privately. The maintainer may remove comments, close discussions, or block
participants who violate this code.
